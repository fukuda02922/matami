| タスク | 週 | 優先度 | 成果物 |
|--------|-----|--------|--------|

| DB設計・投稿API（岐路CRUD） | W4–5 | 高 | PostgreSQL スキーマ・REST API |
| カテゴリ分類（OpenAI + タグ選択） | W5 | 中 | 分類API・タグUI |
| マッチングロジック（pgvector類似検索） | W5–6 | 高 | 共鳴マッチングAPI・Redisキャッシュ |
| ホーム・フィード画面実装 | W6 | 高 | フィードUI（React Native） |
| 投稿・共鳴・マイ岐路画面実装 | W6–8 | 高 | 投稿フォーム・タイムラインUI |
| 通報・ブロック・モデレーション機能 | W8 | 高 | OpenAI Moderation API連携・管理画面 |
| TestFlight配信・クローズドβテスト | W9–10 | 中 | TestFlightビルド・フィードバックシート |
